# Atelier Art Store

A premium Next.js art-commerce starter with demo paintings, responsive gallery pages, cart, demo checkout, contact form and an admin dashboard.

## Run locally
1. Install Node.js 20+.
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

## Production integrations to add
